Gym Shorts Automation

A personal automation tool that generates short fitness videos and uploads them directly to its owner's verified YouTube channel and Instagram account.

Private Utility Notice: Gym Shorts Automation is not a public service. It has no users other than its owner and collects no data from anyone else.

Content Generation

Assembles fitness insights and short workout clips programmatically, rendered and published on a scheduled pipeline.

YouTube API

Uses YouTube API Services with owner authorisation to publish uploaded videos, monitor owner channel view counts, and manage first comments.

Instagram Publishing

Synchronizes generated reels directly to the owner's Instagram profile through standard Meta Graph API endpoints.

Zero Public Data

No external user data is accepted, collected, or stored. Authentication tokens are encrypted within GitHub Actions secrets.

Project Governance & Transparency

Gym Shorts Automation operates exclusively under the personal control of its developer. For full details regarding API data access, credential retention, and third-party service policies, please review our comprehensive Privacy Policy.
