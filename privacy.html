Privacy Policy

Clear transparency regarding API integrations, data access boundaries, and credential security.

Last updated: October 2026
Summary: This application is a private tool used by a single owner to publish videos to that owner's own YouTube channel and Instagram account. It does not collect, track, or share any personal data from other users.

1. What it accesses

With the owner's explicit authorisation, Gym Shorts Automation interfaces directly with the following services:

  • YouTube API Services: Used to upload short-form videos to the owner's authenticated YouTube channel.
  • Channel Metrics: Accesses read permissions specifically to evaluate the owner's own video metrics and view counts.
  • Community Interaction: Posts an automated initial pinned or informational comment directly onto the owner's own uploaded videos.

2. What it stores

Storage is localized and ephemeral, scoped strictly to the execution environment:

  • Media Assets & Metadata: Generated video files, preview thumbnails, and post captions/metadata are written temporarily to the execution device or the automated GitHub Actions runner during task execution.
  • Authentication Credentials: OAuth refresh tokens are stored securely as encrypted GitHub Actions repository secrets. They are never shared, exposed in logs, or transmitted to third parties.

3. What it does not do

Because this project serves exclusively as a private creator utility, it maintains strict privacy safeguards:

  • It does not collect, harvest, sell, or share personal data about any other person or viewer.
  • It has no public end users, consumer accounts, or external client registrations.
  • It does not use behavioral analytics, tracking cookies, advertising networks, or telemetry trackers.
  • It does not read, scrape, or access private data from any other third-party channels or accounts.

4. Third-party services

Videos and content generated by this tool are uploaded directly to YouTube (Google LLC) and Instagram (Meta Platforms, Inc.). Their handling of uploaded media and associated platform interactions is governed by their respective terms and policies:

  • Review the official Google Privacy Policy.
  • Review the official YouTube Terms of Service.

5. Deleting data & revoking access

Access permissions can be audited or revoked at any time. The owner can immediately invalidate all stored access tokens through Google's account management console:

Revoke access: https://myaccount.google.com/permissions

Revoking permissions instantaneously invalidates all active OAuth tokens, preventing any further automated API calls.
